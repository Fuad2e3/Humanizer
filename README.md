# Manush Lekha — Humanizer

AI-generated lekhake manusher moto natural kore rewrite korar website. বাংলা, English ar Banglish teen tai chole.

## Ki ki kore
- **Tone** (Natural, Casual, Formal, Academic, Blog) ar **koto ta bodlabe** (Halka / Majhari / Beshi) bechhe newa jay
- **AI-sounding phrase** ("moreover", "in today's fast-paced world", "plays a vital role"…) holud kore highlight kore
- **Mane check**: rewrite er por Claude original ar notun lekha milie dekhe kono idea harie gelo ba notun kichu jog holo kina
- **Number ar locked word check**: number, naam, brand je shob word lock kora, shegula hubohu ache kina dekhay
- **Sentence rhythm**: sentence length koto ta mishano, bar chart e dekhay
- **Ki bodlalo** tab e word-by-word diff

## Run
`index.html` ekta Claude Artifact hishebe banano. Rewrite ar mane check Claude-er `sample` capability diye chole, tai eta claude.ai te artifact hishebe khulle kaj kore.
Shudhu browser e khulle highlight, number check, rhythm chart kaj korbe, kintu rewrite button kaj korbe na. Standalone chalate hole ekta chhoto backend lagbe je Claude API key diye call korbe.
